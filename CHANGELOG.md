# Changelog

All notable changes to Lextron are documented here.

## [0.1.0] — 2026-05-31

### Added

- Initial Lextron release — independent modular rich text editor
- Workspace packages: `lextron-change`, `lextron-dom`, `lextron-core`, `lextron-formats`, `lextron-modules`, `lextron-ui`, `lextron-themes`, `lextron`
- Themes: snow, bubble, slate, dawn
- **Image resize** module — drag handle when an image is selected (`modules.imageResize`)
- Vite demo at `packages/demo`

### Documentation

- Integration guides under `docs/`
